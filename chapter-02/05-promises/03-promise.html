Promise Comparison: .then() vs async/await

Open the console to see the differences

📋 Método con .then()
Retorno implícito: El último .then() retorna lo que sea
Encadenamiento: Cada .then() puede modificar los datos
fetch("https://api.randomuser.me/?nat=US&results=3") .then(response => response.json()) .then(data => { // Modificamos los datos aquí const modified = { ...data, processed: true, timestamp: new Date().toISOString() }; return modified; // ← Retorno implícito }) .then(result => console.log("Resultado .then():", result));
🚀 Método con async/await
Retorno explícito: return data controla exactamente qué se retorna
Flexibilidad: Puedes modificar el objeto antes de retornarlo
const getAsyncData = async () => { try { const response = await fetch("https://api.randomuser.me/?nat=US&results=3"); const data = await response.json(); // Modificamos los datos aquí const modified = { ...data, processed: true, timestamp: new Date().toISOString(), method: "async/await" }; return modified; // ← Retorno explícito controlado } catch (error) { console.error("Error en async/await:", error); return null; } }; getAsyncData().then(result => console.log("Resultado async/await:", result));

⚖️ Comparación directa
Característica .then() async/await
Sintaxis Cadena de promesas Código síncrono aparente
Retorno Implícito (último valor) Explícito (return)
Manejo de errores .catch() try/catch
Legibilidad Media (anidada) Alta (lineal)
📊 Ventajas de cada método

.then() - Ventajas:

  • ✅ Encadenamiento natural de operaciones
  • ✅ Cada paso puede modificar los datos
  • ✅ Retorno implícito del último valor
  • ✅ Manejo de errores con .catch()

async/await - Ventajas:

  • ✅ Código más legible y lineal
  • ✅ Control explícito del retorno
  • ✅ Manejo de errores con try/catch tradicional
  • ✅ Facilidad para depurar paso a paso
